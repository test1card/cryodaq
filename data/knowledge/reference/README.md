# Reference Documentation

Project reference included when the offline RAG index is built with
`cryodaq-rag-index`:

- `operator_manual.md` (from `docs/`)
- `README.md`, `README.en.md` (from repo root)
- `CHANGELOG.md` (from repo root, sectioned by version)

Эти files читаются прямо из repo через reference loader, не требуют copy.
После изменения запустите `cryodaq-rag-index` офлайн, чтобы включить их в
индекс. Tracked здесь для documentation.
